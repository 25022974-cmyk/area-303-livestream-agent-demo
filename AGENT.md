# Livestream Agent Demo - Agent Instruction

## Tech Stack

- Server: Flask
- Data processing: Pandas
- Web UI: HTML + Jinja2 Templates

Before create any web page, read the styling instructions in `STYLES.md`.
With different page routes, make sure to make them have a unified styles.
If there is any new styles rule needed to be create, put them in `STYLES.md`.
